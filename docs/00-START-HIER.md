# TRACKBACK — start hier

TRACKBACK bestaat uit twee onderdelen:

- **TRACKBACK Spelen** voor de DJ en spelers: kaarten scannen, luisteren en onthullen.
- **TRACKBACK Studio** voor de maker: Spotify koppelen, playlists importeren, muziek controleren en printbestanden maken.

## Direct openen

- Studio: <https://tessavdn-creator.github.io/ons-muziekspel/#admin>
- Spelen: <https://tessavdn-creator.github.io/ons-muziekspel/#play>

In de Documenten-map staan ook twee `.webloc`-snelkoppelingen. Op een Mac opent een dubbelklik direct de juiste pagina.

## Aanbevolen volgorde

1. Open **TRACKBACK Studio**.
2. Koppel Spotify en importeer een playlist.
3. Controleer titels, artiesten en oorspronkelijke uitgavejaren.
4. Vul een editienaam en eventueel een ontvanger in.
5. Print eerst een klein testvel met QR-kaarten.
6. Open **TRACKBACK Spelen** op één DJ-telefoon en test één kaart.
7. Print daarna de volledige editie.

## Belangrijk

- Gebruik voor een spelavond bij voorkeur één DJ-telefoon.
- Een Spotify Client ID is openbaar; een Client Secret of access token hoort nooit in TRACKBACK.
- Persoonlijke cadeau-edities zijn alleen bereikbaar via hun geheime QR/link.
- De Spotify-koppeling is een privéprototype. Een openbare commerciële versie vereist een toegestane en rechtmatig gelicentieerde audiobron.
